# react-native-whats-new

A what's-new carousel for React Native that asks for a store rating when it closes. iOS + Android, no native code.

## Installation


```sh
npm install react-native-whats-new
```


## Usage


```js
import { multiply } from 'react-native-whats-new';

// ...

const result = multiply(3, 7);
```
